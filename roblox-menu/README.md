# Меню в стиле Rocket League для Roblox

**Быстрый запуск:** скачайте `RocketMenu.rbxlx`, откройте его двойным кликом (запустится Roblox Studio) и нажмите **Play**.

Если хотите добавить меню в свою игру, вставьте `MainMenu.client.lua` как LocalScript в `StarterPlayer > StarterPlayerScripts`.

Управление: мышь, стрелки/WASD, Enter, геймпад.
Закрыть меню: `_G.CloseMainMenu()`.
