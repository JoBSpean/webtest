# 🎉 Приложение "Привет!" на Replit

Полностью готовое приложение, которое можно запустить бесплатно на **Replit** (онлайн-хостинг).

## ⚡ Быстрый старт (2 минуты)

### 1️⃣ Перейди на Replit
https://replit.com

### 2️⃣ Создай новый Replit
- Нажми **"+ Create Replit"**
- Выбери **"Import from GitHub"**
- Или просто нажми **"Create"** и выбери **Node.js**

### 3️⃣ Загрузи файлы
Скопируй все файлы в свой Replit:
- `replit_server.js` → `replit_server.js`
- `package.json` → `package.json`
- `.replit` → `.replit`
- папку `public/` → `public/`

### 4️⃣ Запусти!
- Нажми кнопку **"Run"** вверху
- Ждёшь 10-20 секунд
- Открывается окно Preview справа

### 5️⃣ Поделись ссылкой
В окне Preview видишь ссылку вида: `https://hello-app.replit.dev`

Отправь эту ссылку друзьям и они смогут отправлять приветствия! 🎊

## 🚀 Что умеет приложение?

✅ Отправлять сообщение на сервер одним кликом

## 🌐 API Endpoints

**POST /api/send-message**
```json
{
  "message": "👋 Привет!"
}
```

**GET /api/messages**
- Возвращает все сохраненные сообщения

**POST /api/clear-messages**
- Удаляет все сообщения

## 💡 Как кастомизировать?

### Изменить сообщение
В файле `public/index.html` найди строку:
```javascript
message: '👋 Привет!'
```
Замени на свое сообщение.

### Изменить цвета
В `public/index.html` в секции `<style>` ищи:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Изменить заголовок
Найди в HTML:
```html
<h1>Привет!</h1>
```

## ❓ FAQ

**Q: Сообщения сохраняются постоянно?**
A: Нет, они хранятся в памяти сервера. Когда Replit перезагружается, они пропадают. Если нужно сохранение - используй базу данных.

**Q: Сколько это стоит?**
A: Абсолютно бесплатно! Replit даёт 500 часов в месяц.

**Q: Может ли зависнуть?**
A: На бесплатном плане Replit усыпляет неиспользуемые проекты. Платный план (очень дешёвый) - никогда не спит.

**Q: Как пригласить друзей?**
A: Просто поделись ссылкой из Preview окна!

**Q: Можно ли добавить базу данных?**
A: Да! Можно добавить MongoDB или PostgreSQL на Replit.
