# Апекс Картинг

Аркадные 3D-гонки на картах, которые работают прямо в браузере. Без установки, без сервера, без внешних картинок и звуков: вся графика и звук генерируются кодом.

**Как запустить:** откройте `karting/index.html` в браузере (двойной клик тоже работает). Для телефона или друзей выложите папку `karting/` на любой статический хостинг: GitHub Pages, Netlify, Replit.

## Что есть в игре

- **Три трассы** с разной атмосферой:
  - «Солнечная долина»: днём, холмы, S-образная секция, трибуны.
  - «Закатная гавань»: остров на закате, пальмы, море с бликами, шпилька.
  - «Неоновый город»: ночная уличная трасса, фонари, неоновые отбойники, небоскрёбы.
- **Восемь пилотов** с разными характеристиками: скорость, разгон, управляемость, вес.
- **Три режима:**
  - быстрая гонка до 8 участников;
  - «Кубок Апекса» из трёх этапов с очками 10-8-6-5-4-3-2-1 и обратной решёткой;
  - заезд на время с призраком лучшего круга и дельтой в реальном времени.
- **Физика заноса с мини-турбо.** Три уровня заряда: синие, оранжевые и фиолетовые искры.
- **Старт по огням.** Пять красных огней, как в «Формуле-1». Газ после пятого огня даёт идеальный старт, слишком ранний газ — пробуксовку.
- **Предметы:** нитро (и тройное нитро для отстающих), самонаводящаяся ракета, масляное пятно, щит. Шанс выпадения зависит от позиции в гонке.
- **Ускорители на асфальте**, поребрики в поворотах, трава и песок замедляют.
- **Соперники с ИИ:** едут по гоночной траектории, тормозят по профилю скорости, обгоняют, объезжают масло, делают заносы ради турбо, применяют предметы. Три уровня сложности.
- **Интерфейс в стиле картингового логгера:** шкала оборотов из светодиодов, скорость, время круга, дельта к рекорду, таблица позиций, миникарта.
- **Хронометраж как в автоспорте:** фиолетовым отмечен быстрейший круг, зелёным — личный лучший.
- **Звук целиком на Web Audio:** двухтактный мотор (у картов нет коробки передач, обороты растут вместе со скоростью), визг шин, эффекты, синтвейв-музыка.
- **Эффекты:** тени, свечение (bloom), искры, дым, пыль, следы шин, пламя турбо, линии скорости.
- **Управление:** клавиатура, геймпад и сенсорные кнопки на телефоне.
- **Три уровня графики.** Рекорды и настройки сохраняются в браузере.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ | `W` / `↑` | `RT` / `A` |
| Тормоз, задний ход | `S` / `↓` | `LT` / `X` |
| Руль | `A` `D` / `←` `→` | левый стик |
| Прыжок и занос (держать) | `Пробел` / `Shift` | `RB` / `LB` / `B` |
| Предмет | `E` / `X` / `Ctrl` | `Y` |
| Взгляд назад | `C` | нажатие стика |
| Камера | `V` | `Back` |
| Вернуться на трассу | `R` | |
| Пауза | `Esc` / `P` | `Start` |
| Звук вкл/выкл | `M` | |

На телефоне газ нажат автоматически. Слева руль, справа занос, тормоз и предмет.

## Разработка

Исходники лежат в `src/` (ES-модули, Three.js). В `game.js` — готовая сборка, поэтому для игры ничего собирать не нужно.

```bash
cd karting
npm install
npm run build   # пересобрать game.js
npm run dev     # сборка с отслеживанием и локальный сервер
```

| Файл | Что внутри |
|---|---|
| `src/main.js` | запуск, рендер, меню, режимы, игровой цикл |
| `src/race.js` | гонка: старт, круги, позиции, столкновения, призрак, результаты |
| `src/kart.js` | модель карта и аркадная физика с заносом |
| `src/ai.js` | соперники: профиль скорости, обгоны, заносы, предметы |
| `src/trackdata.js` | описания трасс (контрольные точки сплайна) |
| `src/trackgeom.js` | геометрия трассы, гоночная траектория, проекция точки на трассу |
| `src/trackmesh.js` | асфальт, поребрики, отбойники, насыпи, арка старта, ускорители |
| `src/scenery.js` | небо, свет, вода, горы, деревья, трибуны, ночной город |
| `src/items.js` | предметы и снаряды |
| `src/effects.js` | частицы и следы шин |
| `src/audio.js` | синтез звука и музыки |
| `src/hud.js`, `index.html` | интерфейс |

Новую трассу можно добавить в `src/trackdata.js`: достаточно списка точек `[x, z, высота]`. Асфальт, отбойники, гоночная траектория и поведение ИИ строятся по этим точкам автоматически.
