# Апекс Картинг

Прототип спортивного картинга в браузере на Three.js. Четыре реальных картодрома, физика карта без дифференциала, классы Rotax Junior, OK Senior и KZ2, тайминг по секторам, рекорды, облачное сохранение и закрытая админ-зона с нейроэволюцией ИИ. Графика и звук генерируются кодом, внешних картинок и звуков нет.

**Как запустить:** откройте `karting/index.html` в браузере (файл работает и без сервера). Для телефона выложите папку `karting/` на любой статический хостинг.

## Трассы

| Трасса | Место | Длина | Ширина | Круг ИИ: Junior / OK / KZ2 |
|---|---|---|---|---|
| South Garda Karting | Лонато, Италия | 1010 м | 9 м | ≈52 / 49 / 44,5 с |
| Karting Genk | Генк, Бельгия | 1360 м | 9,5 м | ≈61 / 58 / 53 с |
| PF International | Брэндон, Англия | 1382 м | 8,5 м | ≈61 / 58,5 / 53 с |
| Kristianstad (Asum Ring) | Кристианстад, Швеция | 1100 м | 8,5 м | ≈55 / 52,5 / 47,3 с |

- Осевая линия — центростремительный сплайн Катмулла — Рома, масштабированный до официальной длины (1 единица = 1 метр).
- У каждой трассы есть линия старта/финиша, три сектора, пит-лейн со стеной и шатрами команд, поребрики в поворотах, барьеры из покрышек, трава за полотном и резина на гоночной траектории.
- На PFI есть мост: трасса в форме восьмёрки проходит над собой.
- Схемы восстановлены по открытым описаниям и схемам трасс (порядок и характер поворотов, длина, направление). Это упрощённые реконструкции, не топографические копии.
- Старые аркадные трассы («Солнечная долина», «Закатная гавань», «Неоновый город») перенесены в раздел «Фан-трассы». Только там работают предметы и ускорители.

## Физика карта

Модель двухосного карта считается с шагом 1/120 с:

- **Шины-слики.** Сцепление растёт почти линейно до пикового угла увода, после пика резко падает на 22%. Учтены перенос веса (продольный и поперечный), чувствительность шины к нагрузке и комбинированное скольжение (тормоз или газ в повороте съедает боковое сцепление).
- **Жёсткая задняя ось без дифференциала.** В повороте ось подтормаживает карт и создаёт разворачивающий момент. При большом угле руля внутреннее заднее колесо приподнимается: подтормаживание пропадает, сцепление задней оси падает на 12%. Подъём виден и на модели.
- **Тормоза.** У Junior и OK тормоз только на заднюю ось, поэтому при торможении в дуге зад уходит в занос. У KZ2 тормоза на обе оси.
- **Двигатель.** Двухтактник с центробежным сцеплением и слабым «низом». Junior и OK — прямой привод, KZ2 — шесть передач (автомат или ручная коробка).
- **Покрытия.** Поребрик снижает сцепление и трясёт камеру, трава резко тормозит и почти не держит.

| Класс | Макс. скорость | Масса с пилотом | Мощность на колесе | Тормоза |
|---|---|---|---|---|
| Rotax Junior | ~95 км/ч | 145 кг | ~12 кВт | задние |
| OK Senior | ~115 км/ч | 150 кг | ~15,5 кВт | задние |
| KZ2 | ~130 км/ч | 175 кг | ~27 кВт | обе оси |

Помощь руля (в настройках) ограничивает угол колёс на скорости: с клавиатуры иначе легко перекрутить руль и сорвать передок. Без помощи весь угол доступен всегда.

## Режимы

- **Заезд на время.** Выезд из боксов по пит-лейну, круг выхода, затем круги по секторам. Секторы окрашиваются как в настоящем тайминге: фиолетовый — абсолютный лучший, зелёный — личный лучший, жёлтый — медленнее. Есть дельта к рекордному кругу, призрак рекорда, «идеальный круг» из лучших секторов. Если маршалы ставят карт на трассу (`R`), круг не засчитывается.
- **Гонка** до 8 картов со стартом по пяти огням. Три уровня соперников.
- **Чемпионат** из четырёх этапов на реальных картодромах. Очки 10-8-6-5-4-3-2-1, со второго этапа лидер стартует последним.
- **Лаборатория ИИ** — только для администратора (вход через «Админ-зону»).

Рекорды хранятся отдельно для каждой пары «трасса + класс».

## Лаборатория ИИ

Нейроэволюция перенесена из Velocity Grid и адаптирована под карт:

- **Входы сети:** 7 лучей до края полотна (−80°…+80°), скорость, угол к касательной сплайна, смещение от оси, скорость рыскания и снос.
- **Сеть:** 8 скрытых нейронов, два выхода (руль и педаль). Всего 122 общих веса и 48 поправок «памяти поворотов» для 24 участков трассы.
- **Фитнес:** пройденная по сплайну дистанция, за полный круг — бонус за время.
- **Физика у ИИ та же, что у игрока.**
- **Отбор:** турнир, элита, скрещивание, тонкая доводка, случайные новички, автоусиление мутаций при застое. У каждого пилота есть рейтинг MMR.
- **Интерфейс:** 37 настроек с поиском, пресеты, 9 графиков.
- **Сохранения и гараж.** Обучение сохраняется отдельно для каждой трассы и класса: в браузер, в JSON-файл и в облако (если страница открыта как артефакт claude.ai с хранилищем). Лучшие пилоты попадают в гараж: их можно посмотреть на любой трассе, перенести на новую трассу (общие веса сохраняются, память поворотов учится заново) или сохранить именованным снимком.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ | `W` / `↑` | `RT` / `A` |
| Тормоз | `S` / `↓` | `LT` / `X` |
| Руль | `A` `D` / `←` `→` | левый стик |
| Передачи KZ2 (ручная коробка) | `E` / `Q` | `RB` / `LB` |
| Камера: от третьего лица / издалека / сверху | `V` | `Back` |
| Взгляд назад | `C` | `B` |
| Вернуть на трассу | `R` | |
| Предмет (фан-трассы) | `X` | `Y` |
| Пауза | `Esc` / `P` | `Start` |
| Звук вкл/выкл | `M` | |

На телефоне газ нажат автоматически. Слева руль, справа тормоз.

## Разработка

Исходники лежат в `src/` (ES-модули). В `game.js` — готовая сборка, для игры ничего собирать не нужно.

```bash
cd karting
npm install
npm run build   # пересобрать game.js
npm run dev     # сборка с отслеживанием и локальный сервер
```

| Файл | Что внутри |
|---|---|
| `src/main.js` | запуск, рендер, меню, режимы, результаты, игровой цикл |
| `src/race.js` | заезд: старт, тайминг кругов и секторов, позиции, призрак, режимы лаборатории и просмотра |
| `src/physics.js` | физика карта: шины, жёсткая ось, тормоза, двигатель и коробка KZ2, покрытия |
| `src/kart.js` | модель карта (рама, колёса, пилот в шлеме, номер), дым и следы шин |
| `src/ai.js` | соперники: гоночная траектория, профиль скорости по сцеплению, контроль тяги |
| `src/neuro.js` | нейросеть, эволюция, MMR, формат сохранения |
| `src/lab.js` | админ-зона, лаборатория, графики, облако, гараж пилотов |
| `src/trackdata.js` | трассы: точки сплайна, длина, ширина, секторы, пит-лейн |
| `src/trackgeom.js` | геометрия трассы, траектория, пит-лейн, мост, лучи до края полотна |
| `src/trackmesh.js` | асфальт, резина, поребрики, покрышки, пит-лейн, мост, таблички секторов |
| `src/scenery.js` | небо, свет, деревья, трибуны, паддок |
| `src/hud.js`, `index.html` | интерфейс: тайминг, приборы, мини-карта |
| `src/audio.js` | двухтактный мотор, визг шин, эффекты и музыка на Web Audio |
| `src/items.js` | предметы фан-трасс |
